# DealZ V2 – Agent Prompt Pack

These prompts are compact role instructions for the four-workstream workflow described in `docs/19_AGENT_WORKFLOW.md`. They are optional collaborators, not assumed to be connected or running.

## Before starting any agent
1. Read `CLAUDE.md`.
2. Read `docs/11_DESIGN_RULES.md` for all UI work.
3. Read the agent-specific prompt and assigned issue.
4. Read only the contracts referenced by that issue.
5. Do not edit shared contracts without Architect review.

## Prompts
- [C1 – Architect / Integrator](C1_ARCHITECT.md)
- [C2 – Frontend / UX](C2_FRONTEND.md)
- [C3 – Backend / WordPress](C3_BACKEND.md)
- [C4 – AI / Maps / Finance](C4_INTELLIGENCE.md)

All agents must deliver a `HANDOFF.md` containing changed files, contracts, tests/results, setup, limitations and next steps.
